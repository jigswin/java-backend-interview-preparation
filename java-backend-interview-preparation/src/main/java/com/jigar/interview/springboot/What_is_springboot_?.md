# Spring Boot — Q1: What is Spring Boot?

## Answer

Spring Boot is a framework built on top of Spring that makes it easier and faster to develop Java applications, especially REST APIs and microservices.

## Why Spring Boot?

Spring Boot mainly provides:

- Auto Configuration
- Starter Dependencies
- Embedded Server
- Less Configuration
- Production-ready features

## Example

Without Spring Boot:
→ More manual configuration

With Spring Boot:
→ Less configuration
→ Embedded Tomcat
→ Easy REST API development

## Interview Answer

"Spring Boot is built on top of the Spring Framework and simplifies application development by providing auto-configuration, starter dependencies and embedded servers, allowing us to build production-ready applications quickly."

## Remember

Spring = Framework

Spring Boot = Spring + Auto Configuration + Starters + Embedded Server
