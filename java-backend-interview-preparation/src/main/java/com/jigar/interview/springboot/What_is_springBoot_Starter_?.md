# Spring Boot — Q43: What is Spring Boot Starter?

## Answer

Spring Boot Starter ek **predefined dependency bundle** hota hai jo kisi specific functionality ke liye required libraries provide karta hai.

## Example

spring-boot-starter-web

→ REST API / Web application ke liye commonly required dependencies


spring-boot-starter-data-jpa

→ JPA + Hibernate + Database access


spring-boot-starter-security

→ Spring Security


spring-boot-starter-test

→ Testing


## Why use Starter?

Without Starter:

→ Multiple dependencies manually add karni padti hain.


With Starter:

→ Related dependencies ek group me mil jaati hain.


## Interview Answer

"Spring Boot Starters are dependency descriptors that group commonly required libraries for a specific functionality, making dependency management easier and faster."


## Important

Starter
→ Dependencies provide karta hai

Auto Configuration
→ Dependencies ke basis par configuration automatically setup karta hai.


## Easy Memory

Starter
→ WHAT libraries chahiye?

Auto Configuration
