# AWS Q3 — S3

## S3 kya hai?

S3 = Simple Storage Service

AWS ka object/file storage service hai.

Isme hum store kar sakte hain:

→ Images
→ PDFs
→ Videos
→ Documents
→ Backups
→ Logs/files


## Real Example

E-commerce application:

User product image upload karta hai.

Flow:

User
↓
Spring Boot
↓
S3
↓
product-image.jpg


Database me usually:

image URL / object key

store karenge,

actual image S3 me rahegi.


## S3 Structure

S3
↓
Bucket
↓
Objects


Example:

Bucket:
ecommerce-images

Objects:

products/laptop.jpg
products/mobile.jpg
users/profile.jpg


## Bucket kya hai?

Bucket = S3 ka container/folder-like
top-level storage location.

Example:

ecommerce-images


Uske andar:

products/
users/
documents/


## Object kya hai?

S3 me stored actual file ko
Object kehte hain.

Example:

laptop.jpg


Object ke saath metadata bhi ho sakta hai.


## S3 vs EC2

EC2
→ Application/server run karne ke liye


S3
→ Files/objects store karne ke liye


Example:

Spring Boot → EC2

Product image → S3

## Important Benefits

→ Highly scalable storage
→ Durable
→ Easy file access
→ Application server ki disk par dependency kam
→ Backup/static files ke liye useful


## Interview Answer

"S3 is an object storage service used to store files such as images, documents, videos and backups. In a Spring Boot application, I can upload files to an S3 bucket and store the object's key or URL in the database instead of storing the actual file in the database."
